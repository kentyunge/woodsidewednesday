# Woodside Wednesday

Golf league app. See README.md for league rules and setup.

- Scoring rules live in `src/lib/scoring/` as pure functions with tests in `scoring.test.ts`. Change the rules there, never in UI code.
- `src/server/league.ts` (`loadSeason`) is the read model: it computes handicaps, match results and standings on the fly from raw entries. Nothing derived is stored.
- Every mutation goes through `src/server/*` services, which are exposed at `/api/v1` (`src/server/api/app.ts`). UI client components call the API via `src/lib/api-client.ts`, and server components call the services directly.
- Schema changes: edit `src/db/schema.ts`, then run `npm run db:generate`. `src/db/auth-schema.ts` is generated by `npx @better-auth/cli generate`.
- shadcn components are in `src/components/ui` (new-york style); add more with `npx shadcn add <name>`.
- Checks before committing: `npm run lint && npm run typecheck && npm test`.
